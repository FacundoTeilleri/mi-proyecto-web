## 📖 Sobre este repositorio

Este repositorio reúne los proyectos web que voy creando a medida que practico y mejoro mis habilidades de desarrollo. Desde páginas con diseño propio hasta sitios interactivos con alertas personalizadas, cada proyecto es un paso más hacia mi objetivo de ser desarrollador profesional.

## 🛠️ Tecnologías

- **HTML5**: estructura semántica de las páginas
- **CSS3**: estilos, diseño responsive y animaciones
- **JavaScript**: interactividad y lógica del lado del cliente
- **SweetAlert2**: alertas y mensajes modernos y personalizables
- **Git y GitHub**: control de versiones
- **Visual Studio Code / Sublime Text**: editores de código

## ✨ Características

## ▶️ Cómo ejecutar el proyecto

1. Cloná el repositorio:
   ```bash
   git clone https://github.com/FacundoTeilleri/mi-proyecto-web.git
   ```
2. Entrá a la carpeta del proyecto:
   ```bash
   cd mi-proyecto-web
   ```
3. Abrí el archivo `index.html` en tu navegador (doble clic), o usá la extensión **Live Server** de VS Code para verlo con recarga automática.

> 📌 No necesita instalación ni dependencias: SweetAlert2 se carga desde un CDN, así que solo hace falta conexión a internet.

### Cómo se agrega SweetAlert2

```html
<script src="https://cdn.jsdelivr.net/npm/sweetalert2@11"></script>
```
